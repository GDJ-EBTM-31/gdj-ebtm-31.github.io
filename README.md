# GDJ — l'application du groupe de jeunes

Web app installable pour le groupe de jeunes de l'Église Baptiste Toulouse Métropole : les
sujets à préparer au fil de l'année, les rencontres à venir, des lectures et des défis à
cocher.

Tout ce qui est écrit ou coché reste sur le téléphone. Rien n'est envoyé nulle part : le
seul départ possible est un partage ou une sauvegarde que la personne déclenche elle-même.

- `app/` : le site tel qu'il est servi.
- `app/contenu/` : tout le texte — interface, sujets, lectures et défis, agenda, liens.
- `scripts/` : les contrôles lancés avant chaque mise en ligne (contenu, détection des
  navigateurs, contrastes) et les outils de génération.
